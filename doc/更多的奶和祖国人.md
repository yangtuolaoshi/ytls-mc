# 更多的奶，并且可放置

现在不仅可以拿着桶对着牛取奶了，添加了更多生物的奶。

* 这些奶喝下去的效果和牛奶大不相同，尤其是没有牛奶那种清除所有效果的能力，而是根据不同的奶，能带来不同的效果。

* 注意，喝奶获得的效果如果不是一次性的，都应该有持续时长限制。

* 现在，包括原版的牛奶和新添加的奶都可以放置出来了，就像水和岩浆一样。

* 所有奶的流速都略低于水。
* 玩家进入放置出来的奶中，也会获得相应的效果。
* 注意各种生物的幼仔不能产奶。

具体如下表所示（未提及的生物先不做）

| 生物       | 生物的奶     | 喝下效果                             | 进入流体奶中的效果                                           |
| ---------- | ------------ |----------------------------------| ------------------------------------------------------------ |
| 牛（原版） | 牛奶（原版） | 清除所有效果（原版）                       | 清除所有效果                                                 |
| 鸡         | 鸡奶         | 缓降                               | 获得缓降效果                                                 |
| 苦力怕     | 苦力怕奶     | 喝下后爆炸                            | 不需要进入，流体奶放置后本身就会随机爆炸（不破坏方块）       |
| 末影人     | 末影人奶     | 喝下后随机传送（类似于紫颂果）                  | 进入后随机传送                                               |
| 村民       | 村民奶       | 村庄英雄                             | 获得村庄英雄效果                                             |
| 兔子       | 兔子奶       | 跳跃提升                             | 获得跳跃提升效果                                             |
| 潜影贝     | 潜影贝奶     | 飘浮                               | 获得飘浮效果                                                 |
| 蜘蛛       | 蜘蛛奶       | 中毒                               | 获得中毒效果                                                 |

# 祖国人

* 在放置出来的任何流体奶旁边，会随机刷新祖国人。
* 祖国人倾向于走到流体奶当中。
* 可以使用各种奶来喂养祖国人，就如同使用小麦喂养牛羊一般。
* 如果玩家在祖国人面前喝任何奶，会吸引祖国人的仇恨，他们会使用热视线攻击玩家，伤害极高。（激光一样的效果，从头部发出，需要制作特效）
* 祖国人会随机说话（就像原版的牛羊发出叫声那样）
* 祖国人用玩家的模型，材质（皮肤）请预留文件位置

# 玩家产奶

玩家现在也可以产奶了，具体来说

* 添加一个泌乳值，代表着玩家身体中有多少奶，最高积累3000ml

* 这个泌乳值应该显示在显眼的地方，并且标注现在有多少ml的奶

* 将桶拿在手中，按Shift + M，可以收集自己体内的奶，每次收集将消耗1000ml的奶，但必须泌乳值达到了1000ml才能收集，例如现在玩家积累了1500ml的奶，就可以收集一次，而如果只积累了500ml的奶，则无法收集

* 玩家身体里的奶随时间缓慢恢复

* 如果泌乳值达到最高累计上限，玩家全身会持续溢出奶（粒子效果）

* 如果给祖国人喂养玩家的奶，可以驯化祖国人

* 如果玩家喝下玩家奶，会增加泌乳值200ml

* 添加一个催乳剂物品（食物），玩家食用后可以增加自己的泌乳值500ml

  合成表如下

  | 位置 | 材料           |
  | ---- | -------------- |
  | 正中 | 奶（任意的奶） |
  | 上中 | 金苹果         |
  | 左中 | 蜂蜜瓶         |
  | 右中 | 鸡蛋           |
  | 下中 | 金胡萝卜       |

# 奶雨

现在，世界上会随机下起奶雨了（类似于原版的雨、雷暴天气）。

* 默认的奶雨无任何效果。

* 在奶雨期间，祖国人会大量刷新（不需要再放流体奶了，因为天上已经下了好多奶）。

* 玩家可以在工作台合成奶神祭坛，放下后，右键，打开GUI，放入不同的奶可以改变奶雨的成分。

  奶神祭坛的配方如下

  | 位置 | 材料     |
  | ---- | -------- |
  | 正中 | 信标     |
  | 上中 | 灵魂营火 |
  | 左中 | 灵魂营火 |
  | 右中 | 灵魂营火 |
  | 下中 | 灵魂营火 |
  | 左上 | 任意奶桶 |
  | 右上 | 任意奶桶 |
  | 左下 | 任意奶桶 |
  | 右下 | 任意奶桶 |

* 如果玩家被奶雨淋到，也会获得和喝下奶后一样的效果，如下表所示

  | 生物的奶     | 淋奶雨的效果                                                 |
  | ------------ | ------------------------------------------------------------ |
  | 牛奶（原版） | 清除所有效果（原版）                                         |
  | 鸡奶         | 缓降                                                         |
  | 苦力怕奶     | 不需要淋奶雨，只要下起苦力怕奶雨，全世界就会随机爆炸（不破坏方块）（频率在一秒爆炸两三次的那样） |
  | 末影人奶     | 只要淋到奶雨就会随机传送（类似于紫颂果）（注意有CD，不然会无限传送，但CD也比较短，这样能达到比较鬼畜的效果） |
  | 村民奶       | 村庄英雄                                                     |
  | 兔子奶       | 跳跃提升                                                     |
  | 潜影贝奶     | 飘浮                                                         |
  | 蜘蛛奶       | 中毒                                                         |
  | 末影龙奶     | 按F能够吐出龙息（有CD），类似于原版末影龙突出龙息的效果      |
  | 凋零奶       | 按F能够发射调零头颅（有CD），类似于原版凋零发射调零头颅的效果 |

* 如果玩家放下了多个祭坛，但是放入的是不同的奶，效果可以叠加。例如A祭坛放入了鸡奶，B祭坛放入村民奶，淋雨时会同时获得鸡奶和村民奶的效果。
* 提供指令，能够召唤奶雨
