# 吸天气

* 如果正在下雨，对准天空，使用马桶塞右键，整个世界的下雨会停止（变晴天），因为雨被吸走了，并且玩家获得一个雨云物品
* 如果正在雷暴，对准天空，使用马桶塞右键，整个世界的雷暴会停止（变晴天），因为雨被吸走了，并且玩家获得一个雷雨云物品
* 雨云可以放置出来，会生成一团小雨云，雨云下方会下雨
* 雷雨云可以放置出来，会生成一团小雷云，雷云下方会打雷
* 小雨云和小雷云都用粒子效果实现，可以复用原版的一些粒子，这样就不用再做美术设计了

**语义边界（已定稿）**

* 对天判定：抬头俯仰角 ≥ 60°（`getXRot() <= -60`）

# 吸火焰

* 使用马桶塞对准火焰右键，可以消除火焰，并且获得一个火球物品
* 火球有耐久，右键可以喷火，会点燃前方的方块和生物

# 吸爆炸

* 当苦力怕快要爆炸的时候（必须是蓄力一段时间，爆炸之前），使用马桶塞对苦力怕右键，可以将苦力怕的爆炸吸走，苦力怕后续将无法再爆炸
* 吸苦力怕的爆炸时，玩家会获得一个爆炸物品（就叫爆炸）
* 拿着爆炸，右键可以丢出，碰到方块或者实体后会爆炸，会破坏方块，爆炸范围较大

**语义边界（已定稿）**

* 苦力怕蓄力窗口：爆炸前约 1 秒内（swell 进度对应原版 fuse 最后 20 tick）
* 吸走后永久禁爆（PersistentData 标记 + 取消 ExplosionEvent）

# 吸声音

* 手持马桶塞，按V可以切换到吸声音模式，切换后下方文字提示
* 此时右键吸任何实体，都不会造成伤害
* 吸能够发出声音的实体后，能把它们的声音吸出来，存储到马桶塞中，对着空气右键后能够发出这个实体的声音
* 再按V，可以切换回初始模式，保存的声音也会消失

**语义边界（已定稿）**

* 实体声音：收集该实体类型注册表中全部相关音效（`entity.<path>.*`），每次对空右键随机播放一条
