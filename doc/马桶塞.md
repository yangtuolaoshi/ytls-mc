# 总览

现在，马桶塞被加入到了Minecraft里。

Mod风格：

* 荒诞、夸张、搞笑

# 马桶和便便和马桶塞

* 现在，马桶被加入到了Minecraft，它是一个特殊的方块。

* 马桶需要使用稿子挖掘，挖掘等级为木制。

* 马桶的合成表如下

  | 位置 | 物品   |
  | ---- | ------ |
  | 左上 | -      |
  | 中上 | -      |
  | 右上 | 石英块 |
  | 左中 | 石英块 |
  | 正中 | 石英块 |
  | 右中 | 石英块 |
  | 左下 | 石英块 |
  | 中下 | 石英块 |
  | 右下 | 石英块 |

* 玩家右键马桶后，可以坐在上面（需要骑乘动作）

* 玩家坐在马桶上时，马桶里会积累便便，每1分钟积累一个，最多积累3个，积累的数量不同，马桶的样式也不同

* 为了疏通马桶，马桶塞被加入到了Minecraft，它是一个物品。

* 马桶塞的合成表如下

  | 位置 | 物品 |
  | ---- | ---- |
  | 左上 | 皮革 |
  | 中上 | 皮革 |
  | 右上 | 皮革 |
  | 左中 | -    |
  | 正中 | 木棍 |
  | 右中 | -    |
  | 左下 | -    |
  | 中下 | 木棍 |
  | 右下 | -    |

* 手拿马桶塞，右键马桶，可以将便便吸出，掉落物品。前提是马桶里有便便，每吸出一次，马桶内的便便少一个。
* 马桶塞有耐久，每吸收成功一次，就会消耗1点耐久，耐久上限为50。
* 便便是食物，吃下后回复2点饱食度，并且获得反胃3、饥饿3、中毒3，持续10秒。

# 吸更多方块

马桶塞被赋予了强大的能力，右键对其他方块也有作用。

具体来说，会将方块进行转化，并且生成掉落物或者生成实体、生物等等。例如，吸原矿时，就把矿物变成原石，并且掉落矿物物品，就像是把矿物从石头里吸出来了一样。

具体如下表

| 方块                                           | 转换为                             | 掉落       | 生成                     |
| ---------------------------------------------- | ---------------------------------- | ---------- | ------------------------ |
| 草方块                                         | 泥土                               | -          | -                        |
| 各类原木                                       | 去皮原木                           | -          | -                        |
| 各类虫蚀方块                                   | 原始方块                           | -          | 蠹虫                     |
| 各类原矿（包括浅层矿石、深层矿石和下界岩矿石） | 石头（包括浅层的、深层的、下界的） | 对应的矿物 | -                        |
| 各类染色方块                                   | 未染色的方块                       | -          | -                        |
| 各种锈蚀的铜质方块                             | 未锈蚀的方块                       | -          | -                        |
| 各种刷怪笼                                     | 保持不变                           | -          | 对应的怪物，并且大量生成 |

当然，一些特殊的方块，吸它时也会有特殊的效果

* 箱子、熔炉、木桶、发射器、投掷器：会将其中的物品吸出来，每次随机从其中的所有物品中吸出来一个。掉落出来而不是直接放入玩家背包。
* 各种农作物：吸农作物时，有30%概率让它成长（骨粉的效果），70%概率将其破坏掉。

马桶塞也可以被附魔时运效果，会提高掉落物数量，和生成数量，也会在吸农作物时提高成长概率。

# 吸生物

不仅是方块，对于各种生物，马桶塞的右键吸附也有奇效。

* 吸生物后，会对生物造成3点伤害。
* 吸生物后，生物会掉落掉落物，和生物死亡时的掉落物对应。注意，鱼、河豚这种生物就别掉了，不然太op了。
* 特别的，吸村民时，村民会掉落绿宝石。
* 马桶塞也可以被附魔抢夺效果，会提高吸生物时的掉落物数量。

# 吸走实体

* 上面只讲了对方块和生物右键时的效果，而如果是对准任何实体按shift + 右键，则可以直接把这个实体吸走。吸附状态下，实体会跟随玩家移动。
* 吸附状态下，如果玩家再次按下shift + 右键，会将这个实体发射出去。

# 马桶塞枪

* 马桶塞枪被加入到了Minecraft里，用来对马桶塞做终极强化。

* 马桶塞枪是一个特殊的物品，它的合成表如下

  | 位置 | 物品   |
  | ---- | ------ |
  | 左上 | 拌线钩 |
  | 中上 | -      |
  | 右上 | -      |
  | 左中 | 铁锭   |
  | 正中 | 铁锭   |
  | 右中 | 马桶塞 |
  | 左下 | 铁锭   |
  | 中下 | -      |
  | 右下 | -      |

* 马桶塞枪右键后会发射出马桶塞，它的射程较远。有一条线连接马桶塞（类似于鱼竿抛出的效果）和枪体，马桶塞碰到实体、方块、物品掉落物会吸附住。
* 发射后再按右键会收回马桶塞。但是如果吸附了各种东西时，收回的效果不同，具体来说：
  * 实体和物品掉落物：将其拉过来。
  * 方块：将玩家拉过去。
  * 没吸附：直接收回即可。
