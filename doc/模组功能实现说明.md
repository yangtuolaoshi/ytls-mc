# 模组功能实现说明

## 已实现玩法总览

- 新增 11 种可饮用、可放置的奶桶（含玩家奶与可放置牛奶）。
- 除牛以外，支持以下生物拿桶取奶：鸡、苦力怕、末影人、村民、兔子、潜影贝、蜘蛛、末影龙、凋零（幼体不可产奶）。
- 所有奶流体流速低于水；玩家进入奶流体会获得对应效果。
- 苦力怕奶：饮用即爆炸；苦力怕奶流体会周期随机爆炸（不破坏方块）。
- 末影龙奶 / 凋零奶：获得主动能力，按 `F` 发射龙息 / 凋零头颅（有 CD）。
- 祖国人实体：
  - 会在奶流体附近随机刷新；
  - 倾向走向奶流体；
  - 可被任意奶喂养；
  - 玩家当面喝奶会触发祖国人仇恨，并使用高伤害热视线（当前为粒子占位）。
  - 使用玩家奶喂养可驯化。
- 玩家泌乳系统：
  - 泌乳值范围 `0-3000ml`；
  - HUD 左上角显示当前泌乳值；
  - 随时间恢复；
  - 满值时持续粒子溢奶（占位粒子）；
  - 主手拿空桶按 `Shift + M` 收集自身奶（每次消耗 1000ml）；
  - 喝玩家奶 +200ml；
  - 食用催乳剂 +500ml。
- 奶神祭坛与奶雨：
  - 奶神祭坛支持 GUI 放入奶桶；
  - 世界会随机触发奶雨（默认无效果）；
  - 奶雨期间按祭坛内奶类型叠加效果；
  - 奶雨期间祖国人大量刷新；
  - 支持指令：`/milkrain <milkType> <seconds>`。

## 快捷键

- `F`：释放奶能力（末影龙奶 / 凋零奶）。
- `Shift + M`：主手空桶时收集自身奶。

- 由于美术资源与特效资源需要你补齐，已在 `doc/美术与特效占位说明.md` 标注全部占位路径。
