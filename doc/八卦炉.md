# 概述
八卦炉是一个围绕：

* 炼化
* 随机性
* 东方神话
* 混沌造物
* 高反馈战斗道具

展开的功能型 Mod。

玩家可以通过八卦炉，将普通材料炼制为带有神话色彩的特殊法器、兵器与丹药。

# 基本属性

* 是一个功能性的方块，能放置
* 右键可交互
* 需要铁镐挖掘

# 炼制

* 右键交互后打开GUI

* 可以放置燃料和炼制的材料

  * 燃料：熔炉可用的燃料八卦炉都可以用
  * 材料：有三个格子，可以放入不同的物品

* 所有炼制出的成品都是概率出现的，炼制成功后，不同材料的组合（允许随机排列）可以炼制出不同的成品，但是炼制失败后材料会变成一个炉渣；如果不满足成品炼制表（放多、放少、放错），也会开始炼制，但是产出只能是炉渣

  以下是成品炼制表

  | 原材料（3格）                                              | 产出       | 概率 |
  | ---------------------------------------------------------- | ---------- | ---- |
  | 木棍                                                       | 如意金箍棒 | 1%   |
  | 铁锄                                                       | 九齿钉耙   | 1%   |
  | 腐肉 + 骨头 + 蜘蛛眼                                       | 仙丹       | 5%   |
  | 八卦炉 + 龙息 + 蘑菇（红色蘑菇、棕色蘑菇、诡异菌、绯红菌） | 迷你八卦炉 | 10%  |

# 成品特性

## 如意金箍棒

* 是武器，有很高的伤害
* 拿在手上时，按下右键可伸长（暂定可以无限伸长），要能看到模型的变化，并且攻击距离也随之变长，每按下右键一次攻击距离变长一格。按下R后变回原始的长度和攻击距离
* 可以shift + 右键放置；放置出来的金箍棒，可以按照任何方向放置（像末地烛一样）；对其右键也可以变长，每次变长一格，要能看到模型的变化，有实体碰撞，伸长过程中碰到任何方块都将其破坏掉；准星瞄准到它时，按R变回原始的长度；如果变长了，将其破坏后拾取到的金箍棒也是变长过的（参考上一条）

## 九齿钉耙

* 是工具（偏向于锄），但是战斗也有不俗的伤害
* 右键可以耕地，一次可以锄3*3

## 仙丹

* 是食物，回复半格饱食度
* 吃下后获得随机效果，原版里全部的效果中随机抽取一个

## 迷你八卦炉

### 基本设定

- 迷你八卦炉是一个可手持使用的特殊法器道具。
- 玩家手持迷你八卦炉时，按下 `R` 键可以打开专属 UI。
- 迷你八卦炉内部可储存特殊燃料，并通过炼化不同菌类释放持续性的魔炮喷流。

------

### 燃料系统

迷你八卦炉 UI 内共有 4 个固定燃料槽位，每个槽位只能放入指定类型的蘑菇。

| 槽位 | 可放入物品 |
| ---- | ---------- |
| 1    | 红色蘑菇   |
| 2    | 棕色蘑菇   |
| 3    | 诡异菌     |
| 4    | 绯红菌     |

#### 燃料规则

- 每个槽位只能放入对应种类的蘑菇。
- 不允许放入其他物品。
- 不允许将错误种类的蘑菇放入槽位。
- 四种蘑菇的数量分别独立存储与消耗。
- 即使没有集齐四种蘑菇，也依然可以正常使用迷你八卦炉。

------

### 魔炮喷流机制

#### 使用方式

玩家手持迷你八卦炉时：

- 按住右键，可持续释放“魔炮喷流”。
- 松开右键后停止释放。

魔炮并非传统一次性炮弹，而是一种持续喷射的炼化能量流，效果类似火焰喷射器。

------

#### 攻击方式

- 魔炮会向玩家前方持续喷射能量流。
- 能量流具有一定：
  - 射程
  - 扩散范围
  - 持续伤害能力
- 范围内的敌人会持续受到伤害。
- 魔炮会不断刷新目标受到的异常状态。

------

### 燃料消耗机制

魔炮在持续释放期间会不断消耗燃料。

#### 消耗规则

每隔固定时间（例如 10 Tick）：

- 消耗当前已装填的每种蘑菇各 1 个。

例如：

当前装填：

- 红色蘑菇 ×3
- 棕色蘑菇 ×6

则每次消耗周期会：

- 消耗红色蘑菇 ×1
- 消耗棕色蘑菇 ×1

其余不存在的蘑菇不会被消耗。

------

#### 燃料耗尽

- 当某种蘑菇耗尽后：
  - 对应属性立即失效
  - 对应粒子效果同步消失
- 当所有蘑菇全部耗尽后：
  - 魔炮自动停止喷射

------

### 威力机制

魔炮的伤害与效果强度会根据参与炼化的蘑菇种类数量提升。

#### 伤害加成规则

- 每增加一种蘑菇：
  - 魔炮伤害 +2

| 参与炼化的蘑菇种类数 | 额外伤害 |
| -------------------- | -------- |
| 1种                  | +2       |
| 2种                  | +4       |
| 3种                  | +6       |
| 4种                  | +8       |

------

#### 蘑菇效果

不同蘑菇会为魔炮提供不同属性，多个效果可以同时叠加。

| 蘑菇     | 效果                                             |
| -------- | ------------------------------------------------ |
| 棕色蘑菇 | 持续给予敌人减速效果                             |
| 红色蘑菇 | 持续造成爆燃伤害，并产生小范围爆炸（不破坏方块） |
| 诡异菌   | 周期性对命中的敌人触发雷击                       |
| 绯红菌   | 持续点燃敌人                                     |

------

### 粒子与视觉效果

#### 单属性表现

每种蘑菇都会赋予魔炮独特的：

- 粒子效果
- 喷流颜色
- 光效
- 命中特效

例如：

| 蘑菇     | 视觉风格             |
| -------- | -------------------- |
| 棕色蘑菇 | 棕色烟雾与孢子粒子   |
| 红色蘑菇 | 红色火焰与爆燃火星   |
| 诡异菌   | 紫蓝色电弧与闪电粒子 |
| 绯红菌   | 深红火焰与熔蚀粒子   |

------

#### 混合效果

- 当多种蘑菇同时参与炼化时：
  - 粒子效果会进行混合
  - 喷流颜色会动态融合
  - 命中特效也会同步叠加
- 不同燃料组合应具有明显不同的视觉表现，方便玩家直观判断当前魔炮属性。
