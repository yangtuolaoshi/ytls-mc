# 祖国人音效预留

将后续制作好的音效文件放在本目录，文件格式使用 Minecraft 支持的 `.ogg`。

当前代码和 `assets/ytls/sounds.json` 已预留以下音效：

- `ambient_1.ogg`：祖国人空闲/环境语音 1
- `ambient_2.ogg`：祖国人空闲/环境语音 2
- `ambient_3.ogg`：祖国人空闲/环境语音 3
- `hurt_1.ogg`：祖国人受伤音效 1
- `hurt_2.ogg`：祖国人受伤音效 2
- `death.ogg`：祖国人死亡音效
- `heat_vision.ogg`：祖国人热视线攻击音效
- `tame.ogg`：祖国人被玩家奶驯服/喂奶反馈音效

注意：不要放入空白或伪造的 `.ogg` 文件。无效音频文件会导致资源加载报错；在真正音频完成前保留本说明文件即可。
